## 3. 제약 및 미해결 한계

1. **실제 브라우저 DOM 인터랙션 / Google OAuth E2E 미실측**: `next start` 프로덕션 서버 대상 HTTP/SSR 스모크 및 `renderToStaticMarkup` 기반 렌더링 검증은 수행했으나, 실제 헤드리스 브라우저 클릭 인터랙션과 Google OAuth 실계정 쿠키 로그인 흐름은 외부 OAuth 자격 증명/브라우저 미구동으로 미실측 상태이다.
2. **레거시 원격 PostgreSQL(`archive/legacy-postgres/`) 미실측**: 활성 저장 경로인 Standalone `MemoryDatabase`/스냅샷 경로에서 전체 검증을 완료했으며, 비활성 레거시 PostgreSQL 원격 트랜잭션은 원격 DB 미접근 제약에 따라 실측하지 않았다.
3. **기존 작업본 변경 보존**: 시작 전부터 작업 트리에 있던 `.codex/hooks.json`, `AGENTS.md`, 기존 미커밋 수정·문서 파일은 일절 초기화하거나 되돌리지 않고 그대로 보존했다.
