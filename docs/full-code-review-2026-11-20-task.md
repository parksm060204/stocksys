대상: C:/Users/abcde/Desktop/웹소설/stock-sys 현재 작업본 전체(미커밋 및 신규 파일 포함).

에이전트: Antigravity(agy), Hydrogen High. 사용자가 앞으로도 이 워커를 사용하도록 요청했다.

애플리케이션 코드를 수정하지 않는 전체 코드 리뷰를 수행한다. 기존 변경을 보존한다. AGENTS.md를 준수하고 Next.js 판단은 설치된 node_modules/next/dist/docs/ 관련 문서를 확인한다. 추가 워커를 시작하지 않는다.

범위: app 전체 라우트/인증/권한/주문 및 UI 데이터 연결, lib 거래/정산/옵션/원자재/메모리 DB/영속화/동시성, engine-server 엔진/봇/복구, 운영 설정 및 검증 스크립트. 비활성 archive는 활성 코드와 연결될 때만 조사한다. 기존 리뷰 문서와 수정 결과를 참고하되 현재 코드에서 해결된 항목을 다시 결함으로 보고하지 않는다.

검증: 활성 실행 경로를 따라 실제로 발생 가능한 결함을 찾고 심각도 P0~P3, 파일과 정확한 줄, 발생 조건, 영향, 근거, 최소 재현 또는 관련 검증 결과, 수정 방향을 기록한다. 추측 및 미검증 사항은 별도로 분리한다. 실제 사용자 경로와 무관한 임의 내부 상태 주입은 확정 결함의 증거가 될 수 없다. 테스트는 임시 데이터 디렉터리와 프로세스를 격리해 실행하고 실제 .data나 운영 서버에 쓰지 않는다. 타입 검사와 필요한 기존 회귀 검증을 실행하고 실패도 결과로 기록한다. 비정상 종료 자체가 작업 실패를 의미하지 않으며, 원인과 결과를 정확히 보고하는 것이 산출물이다.

수정 허용: docs/full-code-review-2026-11-20-findings.md, 필요한 임시 재현 스크립트(docs 또는 시스템 임시 디렉터리), HISTORY.md 끝에 이번 실제 리뷰 수행 결과 append. 소스/설정/기존 테스트는 수정 금지.

완료 기준: 위 보고서에 영역별 검토 파일/경로와 검증 명령 및 결과, 확정 결함과 잔여 불확실성을 기록한다. 최종 보고는 핵심 결함을 근거와 함께 요약하고 worker_done으로 코디네이터에게 알린다.
